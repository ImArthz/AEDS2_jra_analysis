\begin{abstract}
Este relatório técnico detalha a arquitetura de software, as decisões de engenharia de dados e as estruturas algorítmicas (Teoria dos Grafos) implementadas no pipeline de análise do turfe japonês. Cobrindo o período de 2002 a 2025, o sistema integra dados históricos de corridas de elite (Graded Races) da JRA com bases de linhagens genéticas do JBIS.
\end{abstract}

\section{Introdução e Escopo}
O desenvolvimento deste sistema visa construir uma base de dados altamente confiável e relacional para suportar algoritmos complexos da disciplina de Algoritmos e Estruturas de Dados 2 (AEDS 2), bem como modelagens preditivas futuras em \textit{Machine Learning}. Ao restringir o domínio às corridas de grau G1, G2 e G3, garantimos um \textit{dataset} denso em qualidade competitiva, filtrando ruídos de corridas não-qualificatórias.

\section{Arquitetura Relacional (SQLite)}
O \textit{core} de armazenamento foi projetado sobre SQLite3. O modelo relacional foi estritamente tipado para suportar alto volume e garantir integridade:
\begin{itemize}
    \item \textbf{Tabela \texttt{races}:} Armazena metadados do evento (\texttt{race\_id} (PK), \texttt{date}, \texttt{distance}, \texttt{weather}, \texttt{going}).
    \item \textbf{Tabela \texttt{race\_entries}:} Registra as métricas individuais por atleta (tempo, jóquei, peso físico e de handicap, margem de vitória). Chave estrangeira ligada a \texttt{races} e \texttt{horses}.
    \item \textbf{Tabela \texttt{horses}:} Entidade unificadora. Armazena \texttt{horse\_id} (PK), prêmios financeiros e dados biológicos.
    \item \textbf{Restrição \texttt{ON UPDATE CASCADE}:} Desafio crítico solucionado. Inicialmente, o sistema usava o nome do cavalo como PK temporária. Ao cruzar com o JBIS, a atualização do ID causava violações de \textit{Foreign Key}. A implementação do \texttt{CASCADE} permitiu que a atualização na tabela \texttt{horses} refletisse automaticamente em milhares de registros na \texttt{race\_entries}.
\end{itemize}

\section{Engenharia de Web Scraping e Resiliência}
O motor de coleta foi desenvolvido em Python utilizando \texttt{BeautifulSoup} e \texttt{requests}, implementando \textit{design patterns} de tolerância a falhas.

\subsection{Módulo JRA (Resultados Históricos)}
A extração de dados da \textit{Japan Racing Association} exigiu contornar inconsistências estruturais de mais de duas décadas de código HTML legado. 
Em vez de depender de classes CSS voláteis, o algoritmo rastreia padrões estruturais (ex: tabelas filhas com cabeçalhos contendo 14 colunas específicas). Também foi necessário implementar lógicas de \textit{parsing} para desmembrar colunas concatenadas, como o peso do animal, que historicamente unia o peso base e a oscilação em uma única \texttt{<td>}. Foi inserido um sistema de \textit{Skip Logic} via consultas \texttt{SELECT 1} prévias, economizando latência de rede para corridas já mapeadas.

\subsection{Módulo JBIS (Genética e Perfis)}
No \textit{Japan Bloodhorse Information System}, a extração encontrou outro obstáculo: o uso de Listas de Definição HTML (\texttt{<dt>} e \texttt{<dd>}) no lugar de tabelas convencionais. O \textit{parser} foi adaptado para buscar pares de irmãos no DOM.
Para suportar limites de requisição (\textit{Rate Limiting}), instanciei um controle de \textit{Exponential Backoff} (esperas de segurança progressivas a cada falha) e \textit{Timeouts} agressivos. A árvore genealógica é raspeada via busca em profundidade (DFS) limitada a 5 níveis genéticos, registrando até 62 nós ancestrais por cavalo analisado.

\subsection{DAG de Pedigree (Árvores Genéticas)}
A tabela de ancestrais é convertida em um \textit{Directed Acyclic Graph} (Grafo Direcionado Acíclico). Os vértices representam os cavalos, e as arestas apontam da progênie para seus genitores. Sobre esta estrutura geométrica, executa-se o algoritmo de \textit{Lowest Common Ancestor} (LCA), calculando rapidamente o nível de consanguinidade (\textit{inbreeding}) entre cruzas projetadas.

\subsection{Grafos de Rivalidade e PageRank}
O histórico esportivo é modelado como grafos bipartidos. O peso das arestas reflete as vitórias diretas. Executamos o clássico algoritmo de \textit{PageRank} (Larry Page, 1998) ajustado: um cavalo absorve autoridade exponencialmente não apenas ao vencer, mas ao competir recorrentemente contra lendas de alto ''Rank'', revelando a verdadeira qualidade atlética oculta nas estatísticas lineares.

\section{Conclusão}
O arcabouço tecnológico desenvolvido consolida conhecimentos profundos de Estruturas de Dados, modelagem Entidade-Relacionamento e resiliência de redes (Scraping), entregando um \textit{dataset} limpo, documentado e pronto para arquiteturas complexas de Inteligência Artificial.
